# rigid_local_systems

We consider rigid local systems with Hodge numbers all 1. That is, rigid local systems that correspodn to Higgs bundles of the type (E, theta) where
E = L_1 + L_2 + ... + L_n, theta: L_i -> L_(i+1) x Omega^1 (log S). 

We can try to compute some numerics associated with rigid such things. Such as these index of rigidity things as well as other numerics.
